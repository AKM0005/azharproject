========================================
EARTHWORMX WEBSITE - QUICK SETUP GUIDE
========================================

🎯 IMMEDIATE ACTION REQUIRED:

1. CONTACT FORM SETUP (REQUIRED FOR CONTACT FORM TO WORK)
   ----------------------------------------------------------
   a. Visit: https://formspree.io/
   b. Sign up for a free account
   c. Create a new form
   d. Copy your form ID
   e. In index.html, line 347, replace:
      action="https://formspree.io/f/YOUR_FORM_ID"
      with your actual form ID

2. UPDATE CONTACT INFORMATION
   ----------------------------------------------------------
   In BOTH index.html and about.html, search and replace:
   
   - Email: info@earthwormx.com → YOUR_EMAIL@domain.com
   - Phone: +1 (234) 567-890 → YOUR_PHONE_NUMBER

3. UPDATE SOCIAL MEDIA LINKS
   ----------------------------------------------------------
   In BOTH index.html and about.html footer sections, replace:
   
   - https://instagram.com/earthwormx → YOUR_INSTAGRAM
   - https://facebook.com/earthwormx → YOUR_FACEBOOK
   - https://linkedin.com/company/earthwormx → YOUR_LINKEDIN
   - https://twitter.com/earthwormx → YOUR_TWITTER

4. UPDATE DOMAIN/CANONICAL URL
   ----------------------------------------------------------
   In BOTH files, find and replace:
   - www.earthwormx.com → YOUR_ACTUAL_DOMAIN.com

========================================
❓ COMMON ISSUES:
========================================

Q: Contact form doesn't send emails?
A: Make sure you set up Formspree and replaced YOUR_FORM_ID

Q: Navigation links don't work?
A: They should work fine. Make sure smooth scrolling is enabled.

Q: Images don't show?
A: The Google hosted images should work. If not, replace with your own.

Q: Mobile menu doesn't open?
A: Make sure JavaScript is enabled in your browser.
